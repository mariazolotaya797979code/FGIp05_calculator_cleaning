# Калькулятор клининга

Локальная программа для расчёта стоимости уборки. Во время расчёта интернет не нужен: цены читаются из файла Excel на компьютере.

## Что показывает окно

Слева задают площадь, тип уборки, локацию, выходной или праздник и дополнительные услуги. Справа появляются четыре суммы:

1. Стоимость работ и материалов
2. Накладные издержки
3. Прибыль компании
4. Итого к оплате

## Как считается цена

- База = материалы по площади + работа + отмеченные допы. Часы работы — это большее из минимума часов и площади, делённой на производительность.
- Накладные = транспорт (центр или область) + 1% от цен позиций в штуках и часах + налог от базы.
- Прибыль = маржа от базы. Если отмечены выходной или праздник, к ней прибавляются соответствующие надбавки.
- Итого = база + накладные + прибыль.

Снятая галочка в расчёт не входит. Количество у отмеченной услуги по умолчанию равно 1.

Проценты в таблице можно записать дробью или целым числом: и 0,06, и 6 означают 6%. Число больше 1 программа делит на 100.

## Какой файл с ценами используется

Вверху окна есть переключатель.

- **По ссылке** — файл `calculator_data.xlsx` рядом с программой. Это сохранённая копия таблицы с [Яндекс.Диска](https://disk.yandex.ru/d/CvsQ3e9jhpVWJQ). Программа не скачивает её при каждом запуске, поэтому расчёт работает без интернета.
- **С компьютера** — любой другой файл `.xlsx`. Его выбирают кнопкой «Обзор…».

«Обновить данные» перечитывает тот файл, который сейчас выбран. Если таблица открыта в Excel, её нужно закрыть, иначе программа сообщит, что файл занят.

В книге три листа: Materials, Services и Constants. Столбец «Номер» на расчёт не влияет.

## Запуск из исходников

Нужен Python 3.

```
pip install -r requirements.txt
python calculator_app.py
```

На Windows можно дважды щёлкнуть `start.bat`. На macOS и Linux — `sh start.sh`.

Это окно для компьютера. На Android и iPhone его установить нельзя.
