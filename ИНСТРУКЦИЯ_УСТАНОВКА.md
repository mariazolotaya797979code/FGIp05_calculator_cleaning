# Установка калькулятора на другой компьютер

Нужен архив `Kalkulyator_klininga.zip`. Распакуйте его целиком. Появится папка `Kalkulyator_klininga`, и в ней сразу программа, таблица цен, иконка и эта инструкция.

`Kalkulyator.exe` нельзя выносить из папки отдельно. Файл `calculator_data.xlsx` должен лежать рядом с ним: программа ищет цены в своей папке.

## Windows

Python устанавливать не нужно.

1. Распакуйте архив.
2. Откройте папку `Kalkulyator_klininga`.
3. Запустите `Ustanovit.bat`.
4. На рабочем столе появится иконка «Калькулятор клининга». Дальше открывайте программу этой иконкой.

Можно запустить и сам `Kalkulyator.exe` двойным щелчком. Ярлык удобнее: он открывает программу из папки, где лежит таблица.

Интернет для расчёта не нужен. Если Windows спросит разрешение на запуск, подтвердите его. У файла нет подписи магазина приложений: программа собрана локально.

## Откуда берутся цены

В папке уже лежит `calculator_data.xlsx`. Это копия таблицы по ссылке <https://disk.yandex.ru/d/CvsQ3e9jhpVWJQ>.

В окне сверху два варианта:

- «По ссылке» — расчёт по этой копии;
- «С компьютера» — можно выбрать другой файл Excel кнопкой «Обзор…».

«Обновить данные» перечитывает выбранный файл. Перед этим закройте его в Excel. Иначе программа напишет, что файл занят.

Если на Яндекс.Диске таблицу потом заменили, скачайте новый файл и либо подложите его вместо `calculator_data.xlsx`, либо откройте через «С компьютера».

## macOS и Linux

Готового exe для этих систем в архиве нет. Нужен Python 3. В распакованной папке выполните:

```
pip install -r requirements.txt
python3 calculator_app.py
```

Либо запустите `sh start.sh`.

## Телефон и планшет

На Android и iPhone эту программу поставить нельзя. Окно сделано для компьютера.
