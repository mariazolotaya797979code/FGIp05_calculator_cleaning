Калькулятор стоимости клининга
================================

Windows
1. Распакуйте всю папку целиком. Не вытаскивайте exe отдельно от calculator_data.xlsx.
2. Запустите «Установить.bat». На рабочем столе появится иконка «Калькулятор клининга».
3. Дальше открывайте калькулятор этой иконкой.
   Можно и сразу двойным щелчком по Kalkulyator.exe.

Файл с ценами — calculator_data.xlsx в этой же папке.
Его можно править в Excel. Перед нажатием «Обновить данные» в программе файл нужно закрыть.

macOS и Linux
Нужен Python 3. Запустите в папке:
    pip install -r requirements.txt
    python3 calculator_app.py
Либо: sh start.sh

Телефон и планшет
Это настольная программа. Её нельзя установить на Android или iPhone:
такой интерфейс работает на компьютере, а не в магазине приложений телефона.

Интернет для работы не нужен.
